# 推し活まとめ｜スケジュール更新手順書

このドキュメントは、OWVファンアプリ「推し活まとめ」のイベントマスタ（owv-events.json）を、人間（Amy）とAIが協力して更新するための手順書です。AIに更新を依頼するときは、このファイルごと渡してください。

---

## 1. 仕組みの全体像

- アプリ本体は GitHub Pages で公開された **index.html**（1ファイル完結のWebアプリ）
- ライブ・イベント・CDの「公式データから選ぶ」選択肢は、同じリポジトリ直下の **owv-events.json** から起動時に読み込まれる
- したがって **owv-events.json をGitHub上で差し替えるだけで、アプリ側は変更不要**で全端末に新しい選択肢が反映される
- ユーザーが登録済みのデータ（当落や画像など）はJSON差し替えの影響を受けない（選択肢が変わるだけ）

## 2. owv-events.json の仕様

トップレベル構造:

```json
{
  "app": "oshikatsu-matome",
  "version": 1,
  "updated": "YYYY-MM-DD",   ← 更新した日に書き換える
  "lives":  [ ... ],
  "events": [ ... ],
  "cds":    [ ... ]
}
```

### lives（ライブ）の1件

```json
{
  "title": "OWV LIVE TOUR 2026 -SQUAD- 愛知 1部",
  "tour":  "SQUAD",
  "date":  "2026-07-19",
  "time":  "15:00",
  "venue": "Zepp Nagoya",
  "price": "9000",
  "memo":  "スタンディング(整理番号付き)"
}
```

### events（お話し会・リリイベ等）の1件

```json
{
  "title": "『Lovey-Dovey』リリースイベント 福岡",
  "type":  "リリースイベント",
  "mode":  "オフライン",
  "date":  "2026-08-10",
  "time":  "14:00",
  "place": "ららぽーと福岡 1F メディアパーク",
  "memo":  "補足があれば"
}
```

### cds（CD）の1件

```json
{
  "title": "Lovey-Dovey",
  "version": "通常盤(CD)",
  "releaseDate": "2026-09-30",
  "price": "1400",
  "bonus": "初回プレス分: トレカ(全10種のうち1種)ランダム封入",
  "serial": "個別お話し会抽選対象ページあり(UNIVERSAL MUSIC STORE)"
}
```

### AI向け・記述ルール（必読）

1. **必須項目**: lives/events は `title` と `date`、cds は `title`。それ以外は不明なら**キーごと省略してよい**（空文字でも可）
2. **形式**: 日付は `YYYY-MM-DD`、時刻は 24時間表記 `HH:MM`、金額は**数字のみの文字列**（"9000"。円マークやカンマは入れない）
3. **1部/2部が別々にある公演は、1部と2部を別エントリにする**（titleの末尾に「1部」「2部」を付ける）
4. `time` には**開演時間**を入れ、開場時間は memo に書く
5. `type` は次のいずれか: お話し会 / ヨントン / 握手会 / サイン会 / チェキ会 / リリースイベント / 特典会 / 配信イベント / その他。`mode` は オンライン / オフライン
6. CDは形態（初回限定盤/通常盤/FC限定盤など）ごとに別エントリにする
7. **既存エントリは削除しない**（過去の公演も記録用の選択肢として残す）。追加は日付順の位置に挿入する
8. 当落ステータスや購入枚数などユーザー個人の情報はJSONに**含めない**（アプリ側で入力するもの）
9. 情報源は公式発表（owv.jp、ユニバーサルミュージック等）のみ。**推測で日付や価格を埋めない**。不明な項目は省略する
10. 出力前に必ずJSONとしてパースできることを確認する（カンマ抜け・全角引用符に注意）

## 3. 更新の流れ

### Step 1（Amy）: 情報源をAIに渡す
新しい発表が出たら、AIへのメッセージに以下のどれかを貼る:
- 公式ニュースのURL（例: `https://owv.jp/news/detail/○○○○`）← 一番確実
- 発表のスクリーンショット
- 発表文のコピペ

あわせて**現在の owv-events.json も添付する**（GitHubのファイル画面 → Raw → 全選択コピー、またはファイルをダウンロードして添付）。

### Step 2（AI）: JSONを更新する
- URLが渡されたらフェッチして内容を読み取る（スクショ・貼り付け文ならそのまま読む）
- 上記の仕様・ルールに従って新エントリを作り、渡された owv-events.json に追記した**完成版ファイル**を出力する
- 最後に「何を何件追加したか」を箇条書きで報告する

### Step 3（Amy）: GitHubに反映する
1. Safariで github.com → 対象リポジトリを開く
2. `owv-events.json` を開く → ゴミ箱アイコンで削除 → Commit changes
3. 「Add file」→「Upload files」で新しい `owv-events.json` をアップロード → Commit changes
4. 数分待ってアプリを開き直し、追加フォームの「公式データから選ぶ」に新項目が出ていれば完了
   （反映されない場合は、Safariのタブを閉じて開き直す／ホーム画面アプリを一度終了して再起動）

## 4. AIに依頼するときのテンプレ

以下をコピペして使えます:

> 「推し活まとめ」アプリのイベントマスタを更新してください。添付の「スケジュール更新手順書」の仕様とルールに従うこと。
> ・現在の owv-events.json: （添付 or 貼り付け）
> ・追加したい公式発表: （URL / スクショ / 本文）
> 完成版の owv-events.json をファイルで出力し、追加内容を報告してください。

## 5. トラブル時のヒント

- **選択肢が表示されない** → owv-events.json が index.html と同じ階層にあるか、ファイル名が正確か確認。JSONの文法エラーでも選択肢ごと消える（アプリはエラーを出さず手入力モードになる仕様）
- **JSONが壊れていないか確認したい** → AIに「このJSONをパースチェックして」と渡せばよい
- **アプリ本体（index.html）の変更が必要な修正**（項目の追加・表示の変更など）は、このJSON更新とは別作業。その場合は index.html もAIに添付する
